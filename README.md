\#Todo App

Java/Spring Boot とReactを使用して作成したTodo管理Webアプリケーションです

タスクの基本的なCRUD操作に加え、サブタスク、繰り返しタスク、進捗表示、検索・フィルター機能、タスクの並べ替えなどを実装しています。



\##使用言語・ツール

* Java21
* Spring Boot
* React
* Axios
* MySQL
* ChatGPT



\##主な機能

* タスク一覧表示
* タスク新規作成
* タスク編集
* タスク削除 
* タイトル・詳細を対象とした検索機能
* フィルタリング機能
* ドラッグ＆ドロップによるタスクの並べ替え機能
* サブタスクの完了状況をもとにした進捗表示機能
* 毎日・毎週・毎月の繰り返しタスク自動生成機能




タスクのステータスは以下の5種です。

* TODO
* IN\_PROGRESS
* ON\_HOLD
* DONE
* CANCELLED

サブタスク

親タスクには複数のサブタスクを登録できます
親タスクをDONEに変更すると、紐づくサブタスクもDONEになります。
親タスクの進捗率は、CANCELLEDを除いたサブタスクを対象として計算します

進捗率 ＝ DONEのサブタスク数 / CANCELLEDを除いたサブタスク数 * 100

サブタスクが存在しない場合、またはすべてのサブタスクがCANCELLEDの場合は、親タスクがDONEなら100%、それ以外は0%として表示されます。

繰り返しタスク

繰り返しタスクは以下の繰り返し設定を指定できます

* NONE
* DAILY
* WEEKLY
* MONTHLY

繰り返し設定された親タスクをDONEにすると、次回分のタスクを生成します。
次回タスク生成時には、元タスクに紐づくサブタスクもまとめて複製します。生成された親タスク・サブタスクのステータスはDONEになります。

月次繰り返しでは1日～31日の基準日を指定できます。

検索・フィルター
親タスクが検索・フィルター条件に一致した場合は、その親タスクとその配下のすべてのサブタスクを表示します。

親タスクが条件に一致せず、サブタスクのみが条件に一致した場合は、親タスクと一致したサブタスクを表示します
